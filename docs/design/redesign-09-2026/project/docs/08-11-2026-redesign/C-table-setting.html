Notes
Table Setting
A restaurant magazine. Wine ground for hero bands, brass for accents and ratings, one full‑bleed photograph doing the heavy lifting.
What it fixes
Home opens on a wine hero — a stated headline, a three‑photo collage, and “Browsing from Midtown, New York · change” inline. The default‑location module below is a full section: copy explaining what it affects, address field with “use my location”, saved places, and a 240 px map. Then a three‑cell stat band and a 3‑up “Lately” with your own note as the caption.

Detail kills the blank masthead: the carousel is full‑bleed with the name, cuisine, address and status set over the gradient, arrows top‑right, a 10‑up thumbnail strip beneath, then a three‑column band (my record / getting there / links). Mobile keeps the same overlay and swaps to swipe + dots.

Search sheet gets a wine header holding field and filters, white body for results — no gray anywhere.

Logout is in the avatar menu; the footer becomes a dark colophon that also states who’s signed in.
Palette
#FBF7F3 · #75212F · #B8862B · #241B19 · #F3E4E5
Bricolage Grotesque + Work Sans
Trade-off
This theme leans on real photography. Spots with no photo need a designed fallback — a wine block with the initial set large — or the hero collapses.
