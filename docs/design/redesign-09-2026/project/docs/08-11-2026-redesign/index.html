Four more directions

Each file is one pannable canvas with five frames: / home on desktop and mobile, /spots/:id on desktop and mobile, and /list with the search sheet open — plus a notes card explaining the decisions. Every direction answers the same four problems: an empty home route, a blank detail masthead, a gray search sheet, and a footer carrying logout.

Direction A
Field Notes
Paper ground, hairline ledger rules, serif display. Home reads as a ledger of the collection; detail is a filmstrip carousel beside a spec rail. Tomato and olive replace orange and mint.
Instrument Serif + Manrope
Direction B
Signal
Monochrome utility with an acid accent. Home leads with a ⌘K command bar; detail puts a sticky spec rail beside a full photo grid. Mono for every number and status.
Space Grotesk + JetBrains Mono
Direction C
Table Setting
Editorial, wine and brass. Home opens on a wine hero with a photo collage; detail goes full‑bleed carousel with the name set over the gradient and a three‑column band beneath.
Bricolage Grotesque + Work Sans
Direction D
Night Market
Dark ground, amber action, mint for “tasted”. A glowing map card carries the home route; detail uses a stacked deck carousel. Logout moves into a mobile account sheet.
Sora + DM Sans
