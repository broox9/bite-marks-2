Notes
Signal
Monochrome utility. Hard 1.5 px rules, offset acid shadows, mono for every number and status. Reads like a tool you use daily, not a lifestyle app.
What it fixes
Home leads with the thing you actually do — search — as a centered command bar with ⌘K. Below it a two‑up band: default‑location module (segmented control: saved place / type address / use my location, with saved chips and a live map) and a city + tag index. Then a real data table of recent adds.

Detail inverts the old masthead: a sticky spec rail on the left holds name, address, rating, tags, links, notes and the mini‑map; the whole right side is the photo grid (click to enlarge, arrow keys to step). Mobile falls back to a swipe carousel with the same spec rows.

Search sheet is white on a 2.5 px ink edge with an acid offset shadow, mono result meta and keyboard chips.

Logout lives in the header identity menu; footer is a one‑line status strip.
Palette
#FBFBF9 · #0D0F10 · #D3F94A · #9BBE18 · #D93B1E
Space Grotesk + JetBrains Mono
Watch out
Acid on white fails AA for text — it is used as a fill/highlight only. Status text uses the darker #9BBE18.
